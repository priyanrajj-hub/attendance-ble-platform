# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability in the Amrita Attendance Platform, please do NOT file a public issue on GitHub. Instead, report it privately to the institutional administrators or security team:

- **Email:** `security@amrita.edu` (or repository owner)
- **Subject:** `[SECURITY] Amrita Attendance Vulnerability Report`

Please include:
1. Steps to reproduce the issue.
2. Device model, Android OS version, and network configuration.
3. Proof-of-concept payload or log output (redacting student PII).

We will investigate and address reported vulnerabilities promptly.
